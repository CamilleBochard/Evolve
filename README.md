## ◆ The concept

No classic "about me" page: the site borrows from RPGs. You move between screens as in a pause menu, open a character sheet, a skill tree, a quest log.

The design blends technical brutalism with a game HUD, in a day theme and a night theme.

## ◆ The stack

**Astro** generates a static site: each screen is a real page, served as HTML with no JavaScript by default.

**React** only steps in where interactivity is needed, as islands hydrated on demand. The rest of the page stays light.

Everything is written in **TypeScript**, packaged in a **Docker** image and served behind Traefik.
